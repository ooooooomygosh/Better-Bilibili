# BTR Flow 1.1.0 · 线程撕裂者增强版

完整的 Chrome / Edge 桌面 Manifest V3 扩展，不需要 npm 或编译。基于你提供的 BTR Flow 1.0.0，回移上游截至 **2026.10.4.1** 的适用修复，并重做首页净化与推荐批次操作。

这是独立维护的非官方分支，不是作者发布的最新版扩展。上游在 2026-09-27 停止发布浏览器扩展、转为用户脚本；本包保留现有 MV3 安装方式和 Flow 功能，不会自动更新。详细对应关系见 [上游同步说明](../extension/docs/UPSTREAM_MERGE.md)。

## 从正在使用的 1.0.0 升级

1. 备份现在“已解压加载”的旧扩展文件夹。**不要先卸载**，避免丢失扩展 ID 与设置。
2. 解压本包，把 `BTR-Flow-1.1.0` 文件夹内的所有内容，复制到原来加载的扩展文件夹内，覆盖同名文件。原文件夹路径保持不变；必须是直接包含 `manifest.json` 的那一层。
3. 打开 `chrome://extensions/`（Chrome）或 `edge://extensions/`（Edge），点击现有 BTR Flow 卡片上的“重新加载”。确认显示版本 1.1.0。
4. **刷新所有已打开的 B 站标签页。** 只重新加载扩展，不会自动替换已经注入旧网页的脚本。

不要同时启用两份 BTR 扩展，或同时启用官方线程撕裂者用户脚本。播放器拦截器不能叠加。

首次安装：解压后开启扩展管理页的开发者模式，选择“加载已解压的扩展程序”，选中直接包含 `manifest.json` 的文件夹，再刷新 B 站。此包不是 Firefox、Safari 或 iPad 构建。

## 首页默认会发生什么

大图活动轮播隐藏，轮播留下的网格占位与原有卡片错位边距同时消除。已经加载、却因原布局隐藏的视频卡片可以展开；**不会为了填满屏幕偷偷请求额外推荐**。实际卡片数量和列数仍取决于 B 站返回的数据、页面版本和窗口宽度。

原底部白色悬浮条移除，改成推荐区上方的紧凑操作行：`上一批 · 批次 · 下一批 · 换一批 · 设置`。首页不再同时显示第二个 BTR 悬浮入口；视频页仍保留原来的设置入口。搜索、分区、动态、收藏、原生卡片及其悬停功能不被重写。带明确广告标记的推荐卡片默认隐藏，不按标题或 UP 主做猜测式过滤。

**默认沿用 B 站原生主题。** 升级时旧版强制浅色／深色／跟随系统主题迁移为“原生”。设置中的“纯黑”是可选项：仅在原生深色时把首页背景、卡片底色等主要表面设为 `#000000`；切回原生浅色即退出。它不是全站皮肤，不反色、不处理视频和封面，不接管播放器或独立设置面板的主题。

最顶部季节横幅默认保留。需要更简洁时，在“增强版设置 → 首页”勾选“同时收起顶部季节横幅”。这与默认移除的大图轮播是两个独立开关。

## 推荐历史与换一批

“上一批 / 下一批”只回看已保存的本地快照，不请求新的推荐。“换一批”只调用 B 站现有的换一换入口，先同步加锁防连点，等内容稳定后记录结果。懒加载扩充同一批卡片不会被误计成一批新推荐。找不到原生按钮或超时，会提示并保留已有历史，**不再自动刷新整个网页**。

实时推荐的原生 DOM 保持挂载，不把历史 HTML 塞回 Vue 组件。历史用安全的标题、封面和视频链接单独呈现；历史快照不提供原生悬停预览、稍后再看或“不感兴趣”组件。返回当前批次会恢复原来的卡片和事件处理；Esc 可退出历史。

每个标签页会话最多 25 批、每批最多 36 张视频卡片、7 天有效。关闭历史开关可停止新增；清空时会使在途旧写入失效，避免清空后旧批次重新出现。浏览器存储配额不足时会提示，不阻塞正常刷新。复制标签页可能继承原会话标识，暂不保证复制出来的标签页有完全独立的推荐历史。

## 同步的播放器修复

- **互动视频分支（#34）**：以当前分支 CID 区分播放路由，使用对应预取地址；未预取则请求该段地址，不再始终拿第一段接管。
- **HDR / HEVC 与音轨问题（#29）**：接管前等待原生 SourceBuffer 建立，避免接管竞争引发错误的“不支持编码”记录；只清理上游明确的旧错误标记一次。跟随原生 Hi-Res / Dolby 音轨选择，不支持时回退普通音轨。这不等于为不支持 HDR 或某种音频编码的硬件增加解码能力。
- **自动线程启动**：起播／未缓冲位置跳转时尝试使用 16 并发，缓冲达到 15 秒后逐档回落；遇到真正压力仍能继续提高，30 秒后结束启动阶段。实际并发仍受 Flow 省流策略、用户自动上限和限流冷却约束，不能理解为一律强制 16。
- **诊断与入口**：设置面板新增 GitHub 入口、Debug 诊断复制及剪贴板失败后手动复制。报告标注真实的 Flow / MV3 版本，不假装用户正在使用油猴管理器。视频页悬浮入口不透明度按上游调整。

保留 1.0.0 的多 CDN / Range 下载、智能加载策略、取消与长度校验、内存预算参考、直播支持和可选代理。并发不创造带宽，不能保证你的真实线路上总比旧版更快。

## 代理与权限

必需 API 权限仍只有 `storage`；站点内容脚本仍可读取和修改匹配的 B 站页面。代理功能保留但默认关闭，只能从扩展设置页明确同意并授权后启用；升级不会自动改代理。已有系统代理或 VPN 时，优先保留原分流方式。

本包不提供代理服务、第三方解析、会员／DRM 绕过或地区可用性保证。[隐私说明](../extension/docs/PRIVACY.zh-CN.md) 解释了存储、报告和代理影响。

## 验证、限制与回退

本次通过 **63 项核心测试、30 项模拟页面测试、9 项分支路由／诊断测试、7 项合成媒体 MSE 检查**。测试代码和原始结果包含在包内。合成媒体使用了真实 Chromium 解码器，但网络字节来自本地；其他浏览器 API 按测试说明模拟。

**未完成你的登录态 B 站、真实 CDN、真实扩展安装权限链路、真实代理和 HDR 硬件的端到端验收。** 本地测试页截图不是你账号的真实首页。不能据此宣称所有页面、账号灰度版本或其他净化插件组合都已兼容。与其他插件同时使用时，建议只保留一套首页布局／主题改写。

黑屏或画质菜单异常：在增强设置中切到“兼容模式”并刷新视频页；仍异常则关闭视频加速并刷新，首页功能可以单独保留。首页异常可关闭“启用首页净化与操作栏”恢复原生布局。需要整包回退时，把备份旧文件覆盖回原目录，重新加载扩展并刷新标签页。启用过本扩展代理时，回退／卸载前先关闭本扩展代理。
