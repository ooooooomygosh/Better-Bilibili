# BTR Flow 功能审计（2026-10）

审计对象：用户上传的 BTR Flow 1.1.0（约 8.7k 行源码），审计后发布为 1.2.0。
方法：通读首页增强、弹窗、设置页、页内设置面板、通知层和后台脚本的代码；运行包内全部 Node 测试和 Chromium 回归脚本；在 Chromium 中以「加载已解压」方式实际装载扩展，对路由到本地的模拟视频页做专注模式端到端验证。

> 限制：本环境无法登录 B 站或访问真实 CDN，所有页面结论来自代码阅读和本地模拟页面，不代表在你账号的真实首页上逐项验证过。

标记：✅ 1.2.0 已修复 · 💡 建议，未改动 · ℹ️ 已知限制

## 4. 动画

| | 观察 | 处理 |
|---|---|---|
| 👍 | 通知堆栈（`notification-view.js`）是全扩展做得最好的：统一的 `cubic-bezier(.2,.75,.25,1)` 缓动，进入/移动/退出时长分明，打断时不反向回弹，并尊重「减少动态效果」。 | 保持。新增的专注模式遮罩沿用同一条缓动曲线。 |
| ✅ | 首页切换历史批次、状态提示出现都是瞬间切换，没有过渡，显得生硬。 | 历史快照与状态文字淡入上移 6px；封面悬停轻微放大；按钮颜色过渡。 |
| ✅ | 设置页、弹窗没有任何过渡。 | 按钮/输入框 160ms 过渡、状态文字淡入、用量进度条平滑增长。 |
| ✅ | 新增的过渡全部尊重 `prefers-reduced-motion`。 | — |
| 💡 | 页内设置面板（`settings-panel.js`）的开关、悬浮球过渡没有处理「减少动态效果」。 | 加一条 `@media (prefers-reduced-motion: reduce)`。 |
| 👍 | 从历史返回当前推荐时使用 `scrollTo({behavior:'instant'})` 而不是平滑滚动。 | 合理，长距离平滑滚动容易引起不适。 |

## 5. 新增功能

### 已实现：专注模式（番茄钟）

- 每日观看时长、每日视频个数（播放满 10 秒才算，分 P 合并，正在看的可以看完）。
- 番茄钟：连续观看 N 分钟后休息 M 分钟，圆环倒计时；暂停超过一个休息时长自动重新计时。
- 提醒模式（再看 5 分钟 / 再看 1 个 / 跳过休息）与严格模式。
- 每日重置时间可选 0:00 / 4:00 / 6:00。
- 只统计宽度 ≥ 320px 的主播放器，首页悬停预览不计；后台 Service Worker 是唯一写入者，多个标签页不会互相覆盖。
- 剩余 5 分钟、1 分钟时底部轻提示；额度用完时退出全屏、暂停视频，并拦截空格 / K 键恢复播放。
- 弹窗和设置页显示今日用量进度条；三档快速预设。
- 默认关闭，不需要新增任何浏览器权限。

### 建议后续加入

1. **专注模式进阶**：按星期设置不同额度；学习类分区 / 指定 UP 主不计入；最近 7 天用量图；额度将尽时画面逐渐变灰等更温和的干预。
2. **首页**：用户自己配置的关键词 / UP 主屏蔽（区别于现有只按广告标记过滤）；`Alt + ← / →` 切换批次；收藏某一批历史快照。
3. **播放**：记住默认倍速和画质；自动跳过片头片尾。
4. **分发**：上架 Chrome 应用商店 / Edge 加载项以获得自动更新；在那之前，可在设置页检查 GitHub Releases 有没有新版本。
5. **设置导入 / 导出**，方便换电脑或重装浏览器。
