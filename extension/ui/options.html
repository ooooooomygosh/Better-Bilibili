油门帮你踩，刹车也帮你踩

油门：保留线程撕裂者的多 CDN / Range 下载内核，按视频调整加载策略。刹车：像 Claude Code 一样的 5 小时窗口与每周观看额度，外加番茄钟休息。顺手把首页收拾干净，换一批也能回看。非官方衍生版，不是线程撕裂者作者发布的扩展。

加载与稳定性

不自动降画质

自动策略只调整下载和缓冲；清晰度、字幕、弹幕与倍速仍由播放器控制。

这是上限，不会为了凑数增加请求；手动线程模式不受此项控制。
按码率估算目标时长，不是浏览器总内存限制；音频、解码器和在途数据另占内存。
兼容模式下，缓冲目标和起播门槛由 B 站决定，增强版不强行改写。
快速起播不等于总吞吐更高。若画面掉帧但缓冲很多，瓶颈可能是解码；请在 B 站播放器中调整编码策略，而不是不断增加线程。

首页：保留原生，只减干扰

不接管推荐接口，不重排视频，不改原生卡片。历史操作在推荐区上方，不再悬浮遮挡。

不修改图片或视频，不使用反色滤镜。切回原生浅色会退出纯黑。

B 站自己的「换一换」每次只换两行。开启后，插件会用 B 站首页同一个推荐接口一次请求多批，按「第 N 批」接在原生推荐区下面，右侧显示你正在看第几批。会去重、过滤广告和直播，遇到 B 站限流会自动暂停。

不自动请求更多推荐，只展开页面已经加载的有效卡片。分区、搜索、动态、收藏和原生悬停预览保留。历史快照只保留可点击卡片，不模拟原生预览或“不感兴趣”按钮。

每个标签页最多 25 批 × 36 张卡片，7 天过期，最多 20 组标签页记录。标题、UP 主、封面和链接仅存本地；不保存 Cookie、媒体下载地址或原始 HTML。升级会把旧版自定义深浅主题迁移为原生主题。

节流阀：给 B 站装个用量上限

像 Claude Code 一样计量

两个额度同时生效：5 小时窗口从你开始看的那一秒起算，5 小时后自动重置；每周额度从本周第一次观看起算，7 天后重置。只统计主播放器真正在播放的时间，首页悬停预览不计。

0 表示不限。用完后视频暂停，到点自动恢复。
0 表示不限。周额度用完时，5 小时窗口有余量也会暂停。
0 表示不限。播放满 10 秒才算一个，分 P 算同一个，正在看的可以看完。
连续看满后强制休息；0 表示关闭。暂停超过一个休息时长会重新计时。
快速套用：

提醒模式下的“再看”次数会显示在用量里。数据只存在本机。修改额度立即生效，不会清零已用量；重置时间由首次观看决定，与 Claude Code / Codex 的用量窗口一致。

海外访问：接入已有可信代理

默认关闭。不内置、不推荐公共解析站或免费代理；这里也不是代理订阅客户端。

不是“安装即可解锁番剧”。必须有你自己信任、可连接、出口地区合适的 HTTP / HTTPS / SOCKS5 代理。会员、版权、DRM、登录和平台风控仍可能限制播放；请遵守服务条款。已有 VPN / 系统代理 / 分流软件时，优先直接使用原来的分流，不要重复接管。
本地软件的监听端口不等于大陆出口；出口由该软件选择。不要粘贴订阅 URL 或 PAC URL。不支持在扩展内保存代理密码。

B 站请求不会在代理失败后自动直连。HTTPS 保持浏览器端到端加密；切勿安装陌生代理提供的根证书。代理地址仅存本机。配置不等于线路可用，本包没有附带任何代理服务。
