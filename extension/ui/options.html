油门帮你踩，刹车也帮你踩

加载与稳定性

不自动降画质

自动策略只调整下载和缓冲；清晰度、字幕、弹幕与倍速仍由播放器控制。

这是上限，不会为了凑数增加请求；手动线程模式不受此项控制。
按码率估算目标时长，不是浏览器总内存限制；音频、解码器和在途数据另占内存。
兼容模式下，缓冲目标和起播门槛由 B 站决定，增强版不强行改写。
快速起播不等于总吞吐更高。若画面掉帧但缓冲很多，瓶颈可能是解码；请在 B 站播放器中调整编码策略，而不是不断增加线程。

首页：保留原生，只减干扰

不接管推荐接口，不重排视频，不改原生卡片。历史操作在推荐区上方，不再悬浮遮挡。

不修改图片或视频，不使用反色滤镜。切回原生浅色会退出纯黑。
首页模式

两种刷首页的方式，各自独立，选一个。快捷面板「首页」里也能随时切换。

卡片开关

不自动请求更多推荐，只展开页面已经加载的有效卡片。分区、搜索、动态、收藏和原生悬停预览保留。历史快照只保留可点击卡片，不模拟原生预览或“不感兴趣”按钮。

每个标签页最多 25 批 × 36 张卡片，7 天过期，最多 20 组标签页记录。标题、UP 主、封面和链接仅存本地；不保存 Cookie、媒体下载地址或原始 HTML。升级会把旧版自定义深浅主题迁移为原生主题。

屏蔽：不想看的就别出现

0 条规则

首页原生推荐和无限下滑都会按这些规则过滤；每次换一批、每加载一批都会重新过滤。规则保存在浏览器同步存储里，换电脑也在。

标题关键词

标题里出现就屏蔽，不分大小写、全角半角。写成 /正则/ 可用正则表达式，例如 /第\d+集/。

    UP 主

    填名字（必须完全一致）或 UID。无限下滑卡片的 ⋮ 菜单里也能一键屏蔽，按 UID 记录，UP 主改名也有效。

      视频标签

      B 站视频页下方的那些标签，完全一致才屏蔽。推荐接口不带标签，设置了标签规则后才会逐个查询（每次最多 3 个，结果缓存在本机）。

        净化：去掉 B 站各处的广告和烦人元素

        按页面单独开关

        参照 AdGuard 中文过滤规则正在维护的 B 站广告位，只按明确的广告标记和广告位隐藏，不按标题或 UP 主判断。页面一开始加载就生效，不会先闪一下。

        和 AdGuard、uBlock Origin 等去广告扩展同时使用没有问题：两边隐藏的是同一类东西，叠在一起只是重复隐藏。如果某个页面排版乱了，先关掉这里对应的开关，或在去广告扩展里暂时停用 B 站规则，看看是哪一边引起的。

        节流阀：给 B 站装个用量上限

        像 Claude Code 一样计量

        两个额度同时生效：5 小时窗口从你开始看的那一秒起算，5 小时后自动重置；每周额度从本周第一次观看起算，7 天后重置。只统计主播放器真正在播放的时间，首页悬停预览不计。

        0 表示不限。用完后视频暂停，到点自动恢复。
        0 表示不限。周额度用完时，5 小时窗口有余量也会暂停。
        0 表示不限。播放满 10 秒才算一个，分 P 算同一个，正在看的可以看完。
        连续看满后强制休息；0 表示关闭。暂停超过一个休息时长会重新计时。
        快速套用：

        提醒模式下的“再看”次数会显示在用量里。数据只存在本机。修改额度立即生效，不会清零已用量；重置时间由首次观看决定，与 Claude Code / Codex 的用量窗口一致。

        🔒 自律锁

        未开启

        给观看额度上把锁：收紧（降低额度、开严格模式）立即生效；放宽（提高额度、设为不限、关闭额度、缩短冷却期、解除自律锁）要等冷却期结束才生效，或者输入你设的密码。忘记密码时，只能走冷却期，没有其他后门。

        放宽额度的改动，提交后要等这么久才生效。
        只保存加盐的 PBKDF2 哈希，不保存密码本身。建议让朋友帮你设一个你不知道的密码。

          有密码时，下方任何放宽操作都可以立即生效。
          延长立即生效；缩短要等当前冷却期（或输入密码）。

          诚实说明：自律锁能挡住“随手一关”，但挡不住刻意绕过——卸载或停用扩展、在开发者工具里改扩展存储，都能让它失效。它的作用是给冲动加一道门槛。

          检查与回退

          出现黑屏、清晰度切换异常时，先切到兼容模式，再尝试关闭加速。需要原版详细统计或自定义 CDN 时，在 B 站页面点击扩展图标 → 原版详细设置。

          请禁用旧版扩展和同类油猴脚本，避免同时拦截播放器。本分支不会自动更新。安装说明、审阅报告和测试脚本随压缩包提供。
