哔哩节流阀 BiliThrottle 2.0.0（原名 BTR Flow）— 新增像 Claude Code 一样的 5 小时窗口与每周观看额度，可从 BTR Flow 1.x 覆盖升级，设置保留

此包是非官方 Chrome / Edge MV3 分支，适用修复回移至上游 2026.10.4.1。
作者已停止发布独立扩展，转为用户脚本；本包不是作者官方扩展，不自动更新。

已有 1.0.0：
1. 解压，打开 BiliThrottle-2.0.0 文件夹，确认里面直接有 manifest.json。
2. 将里面的文件覆盖到原来加载的 BTR Flow 目录，保持原目录路径。
3. 在 chrome://extensions/ 或 edge://extensions/ 点击 BTR Flow 的重新加载。
4. 刷新已打开的 B 站标签页，或关闭后重新打开。
不要先卸载，不要再加载第二份目录；否则可能改变扩展 ID 和设置存储。

首次安装：扩展管理页 → 开发者模式 → 加载已解压的扩展程序 → 选择含 manifest.json 的目录。
本包没有 Firefox / Safari 安装包。

不要同时启用另一份线程撕裂者扩展或对应用户脚本。
其他首页净化脚本的重叠功能应关闭其中一份。

默认：去掉推荐区大轮播，工具栏移到推荐区上方，沿用原生浅色/深色。
可选纯黑：扩展图标 → 增强版设置 → 首页背景 → OLED 纯黑。
仅在 B 站深色时改变首页主要底色，不反转封面和视频。
顶部季节横幅默认保留，可在同一设置页关闭。

主页异常：关掉“启用首页净化与操作栏”；播放器异常：切换兼容模式或停用加速。

已通过 108 项本地检查，但当前环境未完成真实扩展安装、登录 B 站或真实 HDR 硬件测试。
完整说明、改动和验证边界见 README.md 与 docs/TEST_REPORT.zh-CN.md。
