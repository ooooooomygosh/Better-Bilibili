# BTR Flow 更新日志

## 1.1.0 — 2026-10-06

### 首页
- 默认去除活动轮播，清除原网格占位、额外间距，并显示已经加载的有效卡片。
- 删除旧强制深色／浅色皮肤，默认跟随原生主题；新增仅在原生深色时应用的首页 OLED 纯黑选项。
- 固定底部大操作条改为推荐区上方紧凑行；仅首页隐藏重复 BTR 悬浮球。
- 保留导航、搜索与季节横幅；横幅可选收起。仅按明确广告标记过滤。
- 新增同步刷新锁、稳定列表检测、无变化超时、按钮失配提示，不再以整页刷新作为自动兜底。
- 原生卡片保持挂载，本地历史快照单独显示，不伪装为可完整交互的原生卡片。
- 历史完整签名覆盖全部卡片；同批次追加、元数据更新合并；限量、过期、延迟写入和清空竞态处理。
- 热路径观察限制于推荐网格；离开首页撤销样式和标记，重建网格时重新挂载。

### 上游回移
- 0.9.4.3：原生 MediaSource 初始化等待、旧编码错误标记修复、Hi-Res／杜比音轨选择。
- 2026.9.29.1：起播自动线程提升与缓冲充足后回落，仍受 Flow 策略上限约束。
- 2026.9.29.2：项目入口、诊断复制、无剪贴板时的手动复制路径，适配本分支版本标识与脱敏。
- 2026.10.4.1：互动视频当前 CID、预取分支缓存、正确分支 API 回退。
- 用户脚本专用存储／注入变更不移植到 MV3；继续使用扩展原生跨子域存储。

### 其他
- 更新设置页面，迁移首页设置但不重置观看策略或启用代理。
- 弹出页在统计字段尚未到达时显示 0 而不是 NaN。
- 108 项本地检查通过；记录真实安装与站点 E2E 未验证的限制。

## 1.0.0 — 用户上传的基线

本次修改的输入为 BTR-Flow-1.0.0(1).zip。原分支包含多 CDN／Range 加载策略、本地推荐快照、首页皮肤及可选代理接入；其上游基线是 0.9.4.2。本次不将原测试报告或旧基准成绩当作 1.1.0 的新验证结果。
