# 哔哩节流阀 BiliThrottle 更新日志

## 2.0.1 — 2026-10-08

### 修复
- **首页「换一批」一直显示更新中，然后超时、页面不刷新。** 真实 B 站首页把「换一换」写成 `div.feed-roll-btn > button.roll-btn > svg + span`，点击处理器绑在里层的 button 上。旧版按文字匹配时先命中外层 div，点击事件不会传给子元素，所以 B 站从未收到刷新请求。现在改为点击显示「换一换」文字的最内层元素：事件向外冒泡，处理器无论绑在 span、button 还是外层容器上都能收到。隐藏原生按钮时，隐藏整个外层包装。
- 新增 `tests/browser-refresh.py`，按真实结构复现这个问题：旧版在该测试中超时，新版通过。

## 2.0.0 — 2026-10-08 · 改名：哔哩节流阀

> Throttle 既是「油门」也是「节流」：加载帮你踩油门，刷多了帮你踩刹车。

### 新的用量额度（像 Claude Code / Codex 一样）
- **5 小时窗口**：从开始观看的那一秒起算，5 小时后自动重置；可设置每个窗口能看多少分钟、多少个视频。
- **每周额度**：从本周第一次观看起算，7 天后重置；周额度用完时，即使 5 小时窗口还有余量也会暂停。
- 遮罩、弹窗和设置页都显示「已用 xx%」和重置时间（如「今天 15:20 重置」「10月14日 周三 21:05 重置」），以及「距离重置还有 3 小时 39 分」。
- 到达重置时间后限制自动解除，无需刷新页面。
- 「再看 5 分钟 / 再看 1 个」只对当前窗口或本周有效，随窗口重置清零；严格模式依旧不提供。
- 番茄钟休息保留；取代 1.2.0 的「每日额度」和「每日重置时间」。

### 改名与新形象
- 扩展名改为「哔哩节流阀 · BiliThrottle」，新图标：带天线的小电视 + 油门表盘。
- 弹窗、设置页、视频页悬浮按钮（「节流」）、页内面板（「节流阀 · 油门」）和提示标题同步改名。
- 内部存储键和消息通道保持不变：从 BTR Flow 覆盖升级会保留所有设置和历史。

## 1.2.0 — 2026-10-08（BTR Flow）

### 新增：专注模式（每日额度 + 番茄钟）
- 每日观看时长上限、每日视频个数上限（播放满 10 秒算 1 个，分 P 合并，正在看的可以看完）。
- 番茄钟：连续观看 N 分钟后弹出休息倒计时；暂停超过一个休息时长自动重新计时。
- 提醒模式可“再看 5 分钟 / 再看 1 个 / 跳过休息”，次数计入统计；严格模式不提供这些按钮。
- 只统计主播放器（宽度 ≥ 320px）真实播放时间，首页悬停预览不计；多标签页由后台统一计数，互不覆盖。
- 每日重置时间可选 0:00 / 4:00 / 6:00；默认关闭，数据只存本机。
- 弹窗与设置页显示今日用量进度条；设置页提供三档快速预设。

### 体验与审美
- 设置页、弹窗支持系统深色模式；输入框聚焦光圈、按钮过渡、状态文字淡入。
- 弹窗的视频加速总开关改为带文字的开关，而不是无标签复选框。
- 设置页修改后显示“有未保存的更改”；清空推荐历史前需要确认。
- 首页操作栏按钮过渡、历史快照淡入、封面悬停微缩放；全部尊重“减少动态效果”系统设置。
