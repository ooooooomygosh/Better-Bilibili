# 哔哩节流阀 BiliThrottle 更新日志

## 2.3.0 — 2026-10-09

### 新增：自律锁（防止随手放宽额度）
- 设置 →「自律锁」。开启后，**收紧**额度（缩短时长、开启额度、开严格模式）立即生效；**放宽**（加时长、关额度、关严格模式、缩短冷却期、解除锁）要排队等冷却期（1 小时 / 6 小时 / 24 小时 / 3 天 / 7 天），或输入密码立即生效。
- 密码可选，只保存加盐的 PBKDF2-SHA-256 哈希（21 万次迭代），不保存密码本身；连续输错 5 次会暂时锁定输入（5 分钟起，逐次加倍）。忘了密码就只能等冷却期——没有后门。
- 锁开启时，「再看 5 分钟 / 再看 1 个 / 跳过休息」需要密码；没设密码就不提供。
- 守卫在后台 Service Worker：快捷面板、弹窗、设置页都只能通过它改额度；直接写入存储的放宽改动会被改回并排队。等待中的改动可以在面板或设置页一键撤销。
- 老实说：这是给自己设的门槛，不是防破解。卸载扩展、用开发者工具改存储都能绕过。
- 不需要新增浏览器权限。

### 无限下滑：卡片和原生一模一样
- 加载出来的卡片改用 B 站原生卡片的结构和类名，直接吃 B 站自己的样式：字体、圆角、深色模式、悬停效果都与原生一致，B 站改版时也会跟着变。
- 悬停封面会预览视频画面（逐帧滑动，与原生的预览图来源相同）。
- 稍后再看：悬停右上角一键加入（使用页面自己的登录状态）。
- 卡片右下角 ⋮ 打开和原生一样的小菜单：添加至稍后再看、不感兴趣、不想看此 UP 主。后两项只在本插件生效（B 站网页没有公开的反馈接口，不会影响你的推荐算法）。选了之后卡片变暗变模糊，中间一行说明和「撤销」；几秒后收起，有备用卡片时补上，保证这一行是满的。
- 每批数量按首页当前的列数取整，最后一行不再缺几张：5 列时 24 → 25、36 → 35、12 → 10，多出来的留给下一批。
- 底部始终有两行骨架卡片表示还在加载，不会出现大块空白；卡片落地后立即可见，只有刚好在屏幕里的卡片播放错开的淡入，不再等待观察器把卡片从透明变出来；封面加载前显示占位底色。
- 右侧「第 N 批」在屏幕中间正好是分隔条或骨架时不再跳回第 1 批。
- 遇到风控不再只显示错误码：说明发生了什么、会不会继续请求，提供「重试」和「切到『稳』再试」，原始错误放在可展开的详情里。

### 快捷面板
- 设置变化时原地更新，不再整块重建：开关的滑动动画不会被打断，用量条只在第一次打开时从 0 长出来，之后平滑过渡。
- 跟随 B 站深浅色主题实时切换；分段选择器加了滑块动画。
- 键盘：`←` `→` `Home` `End` 切换标签（roving tabindex、`aria-controls`、`tabpanel`）；`Tab` 在面板内循环；在输入框 / 评论框里按 `Alt+T` 不再误开面板。
- 悬浮按钮会自动避开 B 站右下角的工具栏；修复面板右侧偏移在窗口变化后被重置的问题。
- 自律锁开启时，面板里显示等待生效的放宽改动，可撤销或输入密码立即生效。

### 额度提醒浮层
- 跟随 B 站深色模式；默认焦点不再落在「离开 B 站」上，避免回车误关页面。
- 自律锁开启时，「再看一会儿」需要密码，并说明原因。

### 首页
- 记住上一次的开关状态，页面一开始就隐藏轮播，减少刷新时轮播闪一下的情况。
- 回看历史批次时淡入切换，封面图加载完再显示。

### 弹窗 / 设置页 / 欢迎页
- 统一配色、字体（含苹方 / HarmonyOS Sans / 微软雅黑）、动效时长；对比度更高，跟随系统深色模式。
- 设置页：所有开关改为滑动开关，**改动自动保存**，底部固定保存状态条；顶部固定分区导航，滚动时高亮当前分区；关闭某功能时，它的子选项变灰并提示原因。
- 弹窗：首页实时显示无限下滑「正在看第几批 / 已加载几批」（直接问页面，不读旧的存储），与「换一批」记录分开说明；不在视频页时不再显示一排「—」，改为一句说明；切换加速后提供「刷新当前页」按钮；用量条原地平滑更新。
- 欢迎页：选「不限制」时说明之前设定的时长会保留；提示动画更柔和。
- 提示文字消失时淡出；重复点击同一个按钮时有反馈，不会看起来像没反应。

### 其他
- 新增 `src/ui-kit.js`（设计变量、动效、深色检测共用一份）和 `src/lock-core.js`；新增 `tests/lock.test.cjs`、`tests/sw-lock.test.cjs`。
- 所有动画尊重系统「减少动态效果」设置。

## 2.2.0 — 2026-10-08

### 新增：快捷面板
- B 站每个页面右下角新增粉色油门按钮（可上下拖动，`Alt+T` 也能打开），常用开关集中到一个面板里，分为三个标签页：
  - **刹车**：开关观看额度、5 小时与每周用量条、自律 / 适中 / 放纵三档预设、严格模式、番茄钟。
  - **首页**：无限下滑（及每批视频数、加载速度）、首页净化、移除轮播、隐藏广告、换一批回看、季节横幅、纯黑。
  - **油门**：视频加速、CDN 路线、观看策略、直播加速；视频页另有「高级播放设置」入口。
- 默认打开最贴合当前页面的标签：首页打开「首页」，视频页打开「油门」。开启观看额度时，按钮外圈实时显示 5 小时额度的用量。
- 首次出现时，按钮旁会弹出一次说明。原来视频页的「节流」悬浮按钮并入这里，页面上不会再出现两个按钮。首页操作栏的「设置」和扩展弹窗都可以直接打开快捷面板。
- 不想要悬浮按钮时可以隐藏，之后从扩展图标打开快捷面板。

### 新增：欢迎页
- 新安装后自动打开，内容包括三步上手、无限下滑和观看额度的一键设置、功能介绍与常见问题。之后可以从快捷面板、弹窗或设置页再次打开。

### 修复
- **无限下滑只有「12 个 / 2 线程」能正常工作，其他组合加载失败。** 原因是插件直接请求 24 或 30 个视频，与 B 站网页的分页参数不一致。现在每次请求固定 12 个（与 B 站网页相同），「每批 24 / 36 个」改为合并 2 / 3 次请求；线程数只决定同时在途的请求数，并且错开 250ms 发出。
- **第一批推荐下面有几行灰色空卡片一直不加载。** 这些是 B 站为自己的懒加载预留的占位。现在会隐藏最后一张真实卡片之后、始终没有内容的占位；「换一换」刷新过程中所有卡片暂时都是骨架时不隐藏，避免页面跳动。
- 只有加载提示真的接近屏幕时才继续加载，不会在后台一口气加载几十批。
- 加载失败时直接显示 B 站返回的错误码，方便定位问题。

## 2.1.0 — 2026-10-08

### 新增：首页无限下滑（默认关闭）
- 设置 →「首页」→「无限下滑」。快滑到底（还剩约 1.5 屏）时，用 B 站首页同一个推荐接口（WBI 签名，带页面自己的登录状态）一次并发请求 1–3 批，按顺序接在原生推荐区下面。
- 每批可选 12 / 24 / 30 个视频；每批前有「第 N 批 · 24 个视频 · 12:47」分隔条；右侧悬浮提示显示当前看到第几批、共加载了几批，点击回到这一批开头。页面右侧空间不足时提示会缩小贴边，不遮挡卡片。
- 与原生推荐、已加载批次去重；过滤广告和直播卡片。批次区块使用 `content-visibility`，滑得再深也不卡。
- 开启后隐藏 B 站自己的懒加载锚点，避免内容在阅读位置上方跳动；关闭后恢复。
- 遇到 B 站风控（-352 / -412 等）立即暂停，显示「重试」，不会继续请求；连续 3 次取不到新内容也会暂停。
- 不需要新增浏览器权限。

### 修复
- 首页本应隐藏的视频页悬浮按钮（「节流」）实际一直显示：页面 CSS 被按钮宿主的行内 `all:initial!important` 覆盖。改为在按钮自己的 Shadow DOM 里用 `:host-context` 隐藏。

## 2.0.1 — 2026-10-08

### 修复
- **首页「换一批」一直显示更新中，然后超时、页面不刷新。** 真实 B 站首页把「换一换」写成 `div.feed-roll-btn > button.roll-btn > svg + span`，点击处理器绑在里层的 button 上。旧版按文字匹配时先命中外层 div，点击事件不会传给子元素，所以 B 站从未收到刷新请求。现在改为点击显示「换一换」文字的最内层元素：事件向外冒泡，处理器无论绑在 span、button 还是外层容器上都能收到。隐藏原生按钮时，隐藏整个外层包装。
- 新增 `tests/browser-refresh.py`，按真实结构复现这个问题：旧版在该测试中超时，新版通过。

## 2.0.0 — 2026-10-08 · 改名：哔哩节流阀

> Throttle 既是「油门」也是「节流」：加载帮你踩油门，刷多了帮你踩刹车。

### 新的用量额度（像 Claude Code / Codex 一样）
- **5 小时窗口**：从开始观看的那一秒起算，5 小时后自动重置；可设置每个窗口能看多少分钟、多少个视频。
- **每周额度**：从本周第一次观看起算，7 天后重置；周额度用完时，即使 5 小时窗口还有余量也会暂停。
- 遮罩、弹窗和设置页都显示「已用 xx%」和重置时间（如「今天 15:20 重置」「10月14日 周三 21:05 重置」），以及「距离重置还有 3 小时 39 分」。
- 到达重置时间后限制自动解除，无需刷新页面。
- 「再看 5 分钟 / 再看 1 个」只对当前窗口或本周有效，随窗口重置清零；严格模式依旧不提供。
- 番茄钟休息保留；取代 1.2.0 的「每日额度」和「每日重置时间」。

### 改名与新形象
- 扩展名改为「哔哩节流阀 · BiliThrottle」，新图标：带天线的小电视 + 油门表盘。
- 弹窗、设置页、视频页悬浮按钮（「节流」）、页内面板（「节流阀 · 油门」）和提示标题同步改名。
- 内部存储键和消息通道保持不变：从 BTR Flow 覆盖升级会保留所有设置和历史。

## 1.2.0 — 2026-10-08（BTR Flow）

### 新增：专注模式（每日额度 + 番茄钟）
- 每日观看时长上限、每日视频个数上限（播放满 10 秒算 1 个，分 P 合并，正在看的可以看完）。
- 番茄钟：连续观看 N 分钟后弹出休息倒计时；暂停超过一个休息时长自动重新计时。
- 提醒模式可“再看 5 分钟 / 再看 1 个 / 跳过休息”，次数计入统计；严格模式不提供这些按钮。
- 只统计主播放器（宽度 ≥ 320px）真实播放时间，首页悬停预览不计；多标签页由后台统一计数，互不覆盖。
- 每日重置时间可选 0:00 / 4:00 / 6:00；默认关闭，数据只存本机。
- 弹窗与设置页显示今日用量进度条；设置页提供三档快速预设。

### 体验与审美
- 设置页、弹窗支持系统深色模式；输入框聚焦光圈、按钮过渡、状态文字淡入。
- 弹窗的视频加速总开关改为带文字的开关，而不是无标签复选框。
- 设置页修改后显示“有未保存的更改”；清空推荐历史前需要确认。
- 首页操作栏按钮过渡、历史快照淡入、封面悬停微缩放；全部尊重“减少动态效果”系统设置。
