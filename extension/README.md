# BTR Flow 1.2.0

保留 B 站原生播放器与推荐卡片，只改善加载、移除首页轮播占位，并让「换一批」可以回看。

**本包是上传版 BTR Flow 1.0.0 的非官方 MV3 更新，不是作者发布的新扩展。** 回移上游 `2026.10.4.1` 的适用修复；上游已经停止独立扩展发行，改为维护用户脚本。本包不具备自动更新服务。

## 1.2.0 新增：专注模式

在「增强版设置 → 专注模式」中启用（默认关闭）。可以设置每日观看时长、每日视频个数、番茄钟连续观看与休息时长、每天几点重置额度，以及是否使用严格模式。达到额度或休息时间时，主播放器会暂停并弹出提示；提醒模式下可以「再看 5 分钟 / 再看 1 个 / 跳过休息」，严格模式不提供这些按钮。只统计主播放器的真实播放时间，首页悬停预览不计；数据只存本机。

## 已经在用 1.0.0 / 1.1.0：这样更新

1. 解压本包，找到 `BTR-Flow-1.2.0` 文件夹，里面应直接包含 `manifest.json`、`src`、`ui`。
2. 将这个文件夹内的文件覆盖到**原来加载的扩展目录**。不要先卸载原扩展，也不要同时加载第二个目录。保持原路径有助于保留扩展 ID、设置和本地历史。
3. 在 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/` 找到 BTR Flow，点击「重新加载」。
4. **刷新已经打开的 B 站标签页，或关闭后重新打开。** 仅重新加载扩展不会清除旧页面里已经注入的播放器代码。

其他「线程撕裂者」扩展或官方同类用户脚本不要同时启用，避免同一播放器被两套加速逻辑接管。同类首页净化插件有重叠开关时，仅保留一份相同功能。

首次安装：打开上述扩展管理页的开发者模式，选择「加载已解压的扩展程序」，选中含 `manifest.json` 的目录。本包沿用原版 Chrome／Edge MV3 形式；没有交付或验证 Firefox／Safari 安装包。

## 你会看到的变化

**大轮播默认移除。** 推荐区的大幅活动轮播不再占据两列、两行；旧布局的间距和隐藏卡片规则同时处理，已经加载的正常视频卡片可以填入腾出的空间。列数沿用 B 站，不强行缩小封面，也不请求额外推荐凑数。

**不再有底部白色悬浮条。** 「上一批、下一批、换一批、设置」放在推荐区上方，正常参与文档布局，不覆盖视频。首页不再叠加第二个 BTR 悬浮球；视频页的原有设置入口保留。

**默认完全沿用 B 站主题。** 旧版本的强制浅色／深色主题会迁移为原生模式。需要纯黑时，从「扩展图标 → 增强版设置 → 首页背景」选择 OLED 纯黑；仅在 B 站处于深色时，将首页背景、卡片、导航等主要底色设为 `#000000`。图片、视频、文字配色不反转，切回原生浅色时不锁在黑色。此选项不是对所有 B 站子页面和弹层的全站换肤承诺。

默认保留顶部季节横幅、分区导航、搜索、动态、收藏、历史以及原生卡片交互。设置里可单独收起顶部横幅。广告过滤仅依据明确广告标记，不根据视频标题、UP 主或题材判断内容。

## 换一批与历史如何工作

新推荐仍由 B 站自己的「换一换」产生，不新增私有推荐接口，不预抓未来批次，不自动滚动或重排内容。

点击后立即锁定操作，避免异步保存期间重复触发。原生列表变化并稳定后才记一批；普通封面延迟加载、作者信息变化和同一批末尾追加卡片尽量合并，不当成新批次。未变化或未达到当前完整性条件时，最多等 10 秒后解锁，保留历史并显示提示；找不到原生按钮时不会擅自刷新整个页面。

「上一批／下一批」查看本地卡片快照，不重新调用推荐接口。原生卡片节点不被克隆替换；退出回看后恢复原生区域。**快照可点击，但没有原生悬停预览或稍后再看按钮**，界面有明确标识。

每个标签页会话最多保存 25 批，每批最多 36 张卡片，7 天过期。打开新页面时清理旧会话，目标最多保留 20 组，浏览器配额可能使实际数量更少。历史可以单独关闭，也可以从设置页清空；清空后拒绝旧的延迟写入重新复活记录。关闭标签页后不保证重新找到原会话，复制标签页可能继承会话标识。

## 播放内核同步了什么

| 上游版本 | 本包适用改动 |
| --- | --- |
| 0.9.4.3 | 等待原生 MediaSource 缓冲区初始化，减少接管竞态造成的 HDR／杜比选项消失；一次性清理特定旧错误标记；跟随播放器 Hi-Res／杜比音轨选择，并保留编码支持判断。 |
| 2026.9.29.1 | 新会话和缓冲外跳转先提高自动线程目标，缓冲充足后逐档回落；保留限流退避、试探无收益回退。 |
| 2026.9.29.2 | 设置面板新增 GitHub 入口及调试信息复制；带签名的媒体地址和敏感字段脱敏，剪贴板失败时提供手动复制文本。 |
| 2026.10.4.1 | 互动视频按播放器当前分支 CID 接管，分开缓存预取分支，不再把下一分支误换回第一段。 |

上游起播自动线程目标为 16；**实际线程仍受 Flow 的观看策略、短视频限制和用户上限共同约束**，不是所有视频都强制开 16 条。保留旧版的 Range 校验、CDN 策略、直播模块、原生播放器界面与画质选择。

油猴／暴力猴之间的存储、注入适配只适用于上游用户脚本。本包用 MV3 的 `chrome.storage.sync` 跨 B 站子域共享设置，没有把用户脚本桥接层再塞进扩展。

## 测试与边界

本次完成 108 项本地检查：63 项 Node 核心测试、29 项首页／设置渲染测试、9 项分支／诊断界面测试，以及 7 项真实 MediaSource 合成媒体测试。

浏览器布局与路由测试使用本地合成页面和明确的 API 模拟；媒体测试使用真实 Chromium 解码本地合成 H.264／AAC 字节。**不是登录 B 站的真实端到端验证，也不是 HDR 硬件或网络加速收益证明。** 当前环境阻止扩展管理页与 B 站真实页面访问，未能完成实际 MV3 安装注入验证。详细结果和可重复运行的脚本见 `docs/TEST_REPORT.zh-CN.md` 和 `tests/`。

`docs/home-oled-fixture.png` 是测试页面的纯黑布局截图，不是用户账号首页的实拍。`docs/options-preview.png` 是本包设置页的本地渲染截图。

## 出现问题时

首页布局异常：关闭「启用首页净化与操作栏」，恢复原生布局；或仅关闭发生冲突的轮播／广告／横幅选项。播放器黑屏或切换异常：先选择兼容模式，再停用加速排查。更新后务必刷新已有 B 站页面；排查时先关闭其他会接管播放器或同一首页布局的脚本。

原版设置面板中开启 Debug 后可复制诊断信息。本包不会自动上传日志；分享前仍应自行检查。代理功能沿用 1.0.0，默认关闭，本次更新不授权、不启用、不更改已有代理，也不提供线路或地区解锁保证。
