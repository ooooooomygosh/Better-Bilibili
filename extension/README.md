# 哔哩节流阀 · BiliThrottle 2.7.0

B 站的油门和刹车：多 CDN 加载、学习 / 美食模式、评论 IP 属地、空降助手、观看额度、自律锁、周报与分享。Chrome / Edge Manifest V3，必需 API 权限仅 `storage`。

## 安装和更新

1. 解压 `BiliThrottle-2.7.0.zip`，找到直接包含 `manifest.json`、`src`、`ui` 的文件夹。
2. 首次安装：打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，选择「加载已解压的扩展程序」。
3. 已安装：将新包内文件覆盖到**原来加载的目录**，在扩展管理页点击「重新加载」。保留目录路径，不卸载，以保留扩展 ID、设置和本机历史。
4. 刷新已经打开的 B 站页面。仅重新加载扩展不会清理旧页面中的播放器代码。

不同时启用另一套线程撕裂者或同类播放器接管脚本。未交付 Firefox / Safari 包。

## 本版使用入口

- **学习 / 美食**：扩展弹窗、设置页、快捷面板「首页」一键切换。学习收起相关推荐与评论；美食保留评论。首页提供主题搜索，不改变 B 站账号的推荐。退出后恢复原偏好，额度和自律锁继续生效。
- **评论 IP 属地**：读取 B 站已公开的地区，不获取精确 IP、不推测位置；设置页可关闭。站点未提供地区时留空。
- **周报**：弹窗「本周报告」，或快捷面板「刹车」。本周同比只比较已结束的完整日；可生成默认隐藏 UP 主的分享图、复制文字、导出每日 CSV。统计在本机保留 10 周，可关闭或清空。
- **干净链接**：视频页快捷面板「油门」复制视频链接，去掉追踪参数，保留分 P。
- **空降助手**：12 个分类，各自配置自动、手动、仅标记或关闭；新增惊吓片段自动静音。
- **播放加速**：同步线程撕裂者 `2026.10.19.2` 的适用修复。番剧/影视独立开关；DRM/试看交回原生。自动线程可选上限 64，默认仍是 32，观看策略可能进一步限制。新安装默认关闭直播加速，升级保留已有状态。

常用面板快捷键：`Alt+T`。在输入框中不拦截快捷键。

## 排查和验证

播放器异常时选择兼容模式或停用加速；首页异常可退出场景模式，再关闭相关净化选项。调试信息只在点击时复制，不自动上传；分享前检查内容。

本版通过 Node 单元测试、加载真实 MV3 扩展的浏览器模拟页面测试、上游播放器回归和安装包完整性检查。公开、未登录的 B 站语言首页也验证了场景入口。完整记录见 `docs/AUDIT-2.7.0.zh-CN.md`。登录态、HDR/Hi-Res 硬件、真实 CDN 吞吐增益仍未验证；历史测试报告不代表本版本的当前测试结果。
