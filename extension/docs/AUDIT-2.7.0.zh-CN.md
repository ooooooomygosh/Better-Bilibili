# 2.7.0 源码审阅与验证记录

日期：2026-10-23。范围：2.6.0 → 2.7.0 的运行代码、上游回移、设置迁移、周报导出、权限、构建及发布流程。此记录是开发阶段源码审阅和可重复测试，不是第三方安全审计认证。

## 审阅发现与处理

| 问题 | 本次处理与验证 |
| --- | --- |
| 中转媒体签名不能直接移植到普通 CDN；原生和接管内核可能重复下载 | 同步上游中转判断、缓冲调度锁及停止恢复；内核锁回归、CDN 单测通过 |
| 音频时钟继续走而视频缓冲耗尽 | 上游保护扩展到完整播放会话，保留本分支慢启动回退；缓冲窗口与慢启动回归通过 |
| 剧集接管可能与 DRM / 试看冲突 | 独立开关，仅兼容接管，不支持的播放清单交回原生；番剧路由回归通过 |
| 新模式可能覆盖首页偏好或放宽自律锁 | 场景独立存储，仅修改显示；实际 MV3 浏览器测试确认额度、锁和首页配置不变 |
| 评论复用节点可能留下前一条属地；嵌套 Shadow DOM 易漏识别 | 只读取公开文本，延迟发现、复用清理、原生去重、关闭时移除；不发查询请求 |
| 播放记录跨午夜 / 小时误归档，满小时后漏计 | 按实际时间分段；午夜保留 30 秒去重窗口；小时桶支持多个标签与回拨重复小时 |
| 未完成一天的同比误导 | 双方均排除今天；周一暂不比较；缺失记录用「没有记录」描述 |
| 分享图可能暴露 UP 名字，后台刷新使输出和预览不一致 | 默认隐藏 UP；打开面板固定快照；复制失败提供选中文本；CSV 不含身份字段 |
| 分 P 查询失败误用其他 CID 的片段 | 不回退到第一 P；未知 CID 只允许无 CID 的历史通用标注 |
| 静音无视每类模式 | 自动 / 手动 / 仅标记各自生效；惊吓分类默认自动静音 |
| 发布分支缺少浏览器检查；随包许可证元数据过时 | main / 已合入 main 的标签才可发布，复用完整 CI；BUILD_INFO 修正为 GPL-3.0-or-later |

未发现阻止本次合并的未修复问题。此结论以以下覆盖范围为限。

## 本机验证

环境：macOS，Node 24.14.0，Python 3.12，Playwright 1.64.0 配套 Chromium（全新临时配置，加载实际 MV3 扩展）。

| 验证组 | 通过数 | 内容 |
| --- | ---: | --- |
| Node `extension/tests/*.test.cjs` | 163 | 播放、配额、锁、存储、筛选、请求退避、统计、模式、属地文本和分享链接等 |
| `browser-upstream.py` | 4 组 | 上游原生内核锁、剧集路由、帧诊断、缓冲窗口，每组包含多项断言 |
| `browser-experience.py` | 6 | 实际扩展的模式开关 / 退出、跨页面同步、评论嵌套与复用、设置和锁保留 |
| `browser-report.py` | 13 | 深浅主题、完整日对比、周导航、对应周提醒、分享隐私 / 快照 / 回退、CSV、移动宽度、真实播放记账 |
| `engine-browser.py` | 9 | 互动分支 CID、原生音轨偏好、诊断脱敏与复制回退 |
| `engine-slowstart.py` | 5 | 慢启动交回原生、手动重试、正常播放不误回退 |
| `browser-sponsorblock-fixture.py` | 8 | 欢迎页、哈希查询、CID、进度标记、真实视频解码后的跳过与撤销、实时开关 |
| `browser-preview-settings.py` | 3 | 弹窗 / 设置的预览和静音选项 |

浏览器共 48 个记录场景 / 组，原始结果位于源码 `extension/tests/*-results.json`。运行时 JS 全部通过 `node --check`，`git diff --check` 无空白错误。源码 SHA-256、两次构建一致性、ZIP 内容与逐文件 SHA-256 均检查。

复现入口：

```sh
node --test extension/tests/*.test.cjs
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install --with-deps chromium
python3 scripts/checksums.py
python3 scripts/browser-tests.py
./scripts/build.sh
```

CI 在 Linux / Node 24 重跑同一套测试。发布工作流在最终 main 提交上再次执行，然后打包发布 ZIP 与 SHA-256。浏览器结果中的实时时长可能相差一两个 tick，不要求 JSON 的字节完全一致；安装包不包含测试文件。

## 真实站点检查及边界

- 无登录公开首页访问成功，海外重定向 `/zh-Hans` 下学习入口显示、原推荐隐藏，无页面异常；由此补齐语言首页路由和容器选择器。
- 真实站点空降助手脚本受当时播放器 / 进度条结构和网络状态影响，未完成全流程；发布门禁使用真实扩展和解码器配合本地 API / 媒体响应，真实站点脚本仍单独保留。
- 未验证登录态、会员 / HDR / Hi-Res 硬件、完整真实番剧站点流程、其他扩展共存或真实 CDN 吞吐收益；不据模拟测试声称这些已通过。
- 系统分享依赖浏览器 / 操作系统能力，测试覆盖复制失败回退，不把打开真实系统分享面板算作已验证。
- 评论属地依赖站点公开数据和 DOM；没有地区字段就留空。场景入口使用主题搜索，不是语义分类或推荐训练。
- 统计沿用每天最多 24 小时、每日 400 个视频去重项、30 个 UP 明细的有界存储；极端多标签长时间播放和大量视频下不适合作精密计费。旧版本已丢失的数据无法重建。
