# 1.1.0 代码复核摘要

## 已修复的具体问题

原刷新实现先异步保存再锁定，快速连点可能重入；现在在触发任何异步操作或原生事件之前设置 busy。原「找不到换一换」路径自动 location.reload；现在明确提示并保留原页面，不做自动重载。

旧历史签名只看部分卡片；现在覆盖保存的全部卡片。列表动态填充、封面更新不再一律另存一批，稳定窗口用于减少中间状态入库；这是一种保守 DOM 检测，不是对 B 站内部请求完成信号的精确订阅。

清空与延迟存储写入可能相互覆盖；现在使用全局清空 epoch 和本地写入代次，过期写入到达后会被拒绝。存储不可用时保留内存回看，并显示实际失败，不将错误声称为保存成功。

移除轮播不只设置 display:none：同时处理原网格间距、区域约束和已经加载但被隐藏的有效卡片。明确广告标记的隐藏规则在有效卡片显示规则之后且优先级足够，避免清理轮播时反而把广告重新显示出来。

纯黑检测先撤掉本插件自己的覆盖，再测量原生底色，避免用户切回浅色时被自身黑色背景锁定。旧强制主题被迁移到原生，未再做全站自定义暗色皮肤。

## 交互与性能边界

原生卡片保留在其框架树里，不通过 innerHTML 快照替换，不试图复制事件监听器。历史快照用安全文本／链接另行呈现，并明确说明没有悬停预览。

MutationObserver 的高频路径限制于推荐网格；整个 body 只做子节点重建发现，没有全页属性监听。另有每秒一次的路径字符串比较用于发现 SPA 路由变化，不改写站点 History API。保存去抖和旧会话清理不在每次 DOM mutation 中执行。

不会为了补满两行不断刷新、预取推荐或进行合成滚动；能显示多少正常卡片受页面原本加载的数据限制。不声称首页推荐内容更优、播放器更快的固定百分比或所有 A/B 页面都适配成功。

## 仍需真实环境确认

MV3 安装注入、登录后的真实 B 站 DOM 与账号 A/B 布局、真实网络收益、HDR／Hi-Res／杜比硬件播放、长期内存曲线、Firefox／Safari 均未完成验证。浏览器管理策略阻止本环境的扩展管理页和真实 B 站访问，未尝试绕过。

当前代理逻辑、Range／CDN 策略与直播主体沿用原分支；没有启用代理或替用户访问账号。此文是实现自查，不是第三方安全认证。
